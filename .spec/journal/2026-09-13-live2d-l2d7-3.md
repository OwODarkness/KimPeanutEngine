# Live2D L2D7.3 — Immutable Queries and Hit Testing

- Date: 2026-09-13
- Status: implementation baseline; L2D7.4/L2D7.5 remain open.

## Delivered

- `Live2DModelResource` now exposes ordered immutable Product V3 user data and hit-area metadata, plus first-match lookup by target type and ID.
- `Live2DModelInstance` resolves authored drawable IDs during staged construction, rejecting unknown IDs before publication.
- Added SDK-free model-local hit queries over current deformed drawable vertices using inclusive axis-aligned bounds. Results preserve authored hit-area order.
- Non-finite points, unknown names, empty/non-finite geometry, and incomplete resolution return deterministic diagnostics without mutating instance state.

- `ctest --test-dir build -C Debug -R Live2D --output-on-failure` — 54/54 passed.

## Remaining
