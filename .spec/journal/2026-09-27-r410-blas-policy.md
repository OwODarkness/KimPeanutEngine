# R4.7.10 static-BLAS policy — 2026-09-27

## Investigation

The R4.7 plan calls for isolating traversal/BLAS policy from TLAS policy,
preserving geometry, and measuring startup/build cost and memory. Existing
R4.7.3 results showed a static fast-trace trial reach active PT at
786,098,304 bytes of AS storage, then fail during upload queue idle with
`VK_ERROR_DEVICE_LOST`; they did not establish a usable timing comparison.

This pass added `VK_BUILD_ACCELERATION_STRUCTURE_PREFER_FAST_TRACE_BIT_KHR`
only for non-updatable BLAS builds in the Vulkan acceleration-structure owner.
TLAS and updateable AS flags are unchanged. The existing `build_info` supplies
both the size query and build call, retaining flag parity. Geometry, scene-table
mapping, ownership and retirement behavior were not edited. The existing
Sponza light-intensity change (1000) was preserved.

## Validation and evidence

- Rebuilt baseline RelWithDebInfo before the edit using
  `tools/kp.ps1 -Configuration RelWithDebInfo build KimPeanutEngine`: passed.
- One visible baseline Vulkan Sponza profile window completed: 1094x619,
  path tracing active, 4 SPP, 8 continuation bounces, 120 warm-up / 300 samples,
  complete tracked texture residency 469,888,580 bytes, AS storage
  728,189,952 bytes. PT GPU p50/p95 23.673/24.379 ms and total GPU p50/p95
  28.368/29.003 ms. This window was not accepted as a stable baseline because
  telemetry varied from 210 to 1080 MHz graphics clock and memory from 405 to
  6001 MHz.
- Rebuilt after the edit with the same command: passed; the Vulkan owner and
  engine executable compiled/linked. No tests were run.
- A subsequent baseline run failed timestamp reads and command-buffer
  submission; Windows recorded NVIDIA `nvlddmkm` Event 153 twice. Runtime
  sampling stopped. The candidate has not been launched, so its AS memory,
  startup/build cost, traversal time, output equivalence and scene-replacement
  lifetime behavior are unknown.
- Artifacts: `save/diagnostics/r410-baseline-sponza-window-1.json`,
  `save/diagnostics/r410-baseline-sponza-gpu-1.csv`, and
  `save/logs/2026-09-27/KimPeanutEngineLog-2026.09.27-18.19.47.txt`.

## Remaining work

Wait for a stable Vulkan/device state, then collect matched repeated baseline
and candidate RelWithDebInfo windows, compare captures, build time and AS
storage, and validate scene replacement/lifetime behavior. Inspect geometry
overlap before considering layout changes; only test static compaction when
measured memory pressure justifies it. R4.7.10 remains open, and no speedup is
claimed.

## Matched policy evaluation — 2026-09-27

Rebuilt and measured both variants using the RelWithDebInfo Vulkan Sponza
editor. The candidate was measured first, followed by the no-preference
baseline. Each mode used three windows with 120 warm-up and 300 measured
frames, Beauty at 4 SPP/eight bounces, the same 1094x742 viewport, and complete
469,885,796-byte texture residency. The fixture's edited light intensity of
1000 was preserved.

| Variant | PT p50 windows (ms) | PT p50 mean | PT p95 mean | Total p50 windows (ms) | Total p50 mean | Total p95 mean |
|---|---:|---:|---:|---:|---:|---:|
| No preference | 27.749 / 27.746 / 27.771 | 27.755 | 30.541 | 32.430 / 32.431 / 32.478 | 32.446 | 35.454 |
| `PREFER_FAST_TRACE` | 29.278 / 29.102 / 29.228 | 29.203 | 33.219 | 34.137 / 33.990 / 34.035 | 34.054 | 38.172 |

Fast-trace increased mean PT GPU p50 by 5.2%, total GPU p50 by 5.0%, PT p95 by
8.8% and total p95 by 7.7%. No in-window GPU clock/temperature telemetry,
candidate AS storage, image comparison or scene-replacement validation was
captured, so this rejects the hint for this Sponza setup without completing the
broader acceptance gate. The static-BLAS preference was removed and the
RelWithDebInfo no-preference build passed. No tests were run. Raw samples and
summaries are ignored build artifacts under `build/NsightGPUTrace/`.

The first attempt with `--resize` failed before measurement because its
command-port/runtime startup was unstable. Returning to the normal viewport and
using fresh command ports allowed the matched windows to complete.
