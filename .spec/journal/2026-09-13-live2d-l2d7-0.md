# L2D7.0 Phase Reconciliation — 2026-09-13

- Status: implementation baseline; L2D7.1–L2D7.4 remain ordered follow-up work.
- Scope: reconcile the L2D6 playback seam with the pinned Cubism R5 behavior
  order while preserving the existing public playback contract.

## What landed

`Live2DModelInstance::AdvancePlayback` now exposes private named phases for:

```text
Load checkpoint
apply direct/base writes
primary motion
save primary checkpoint
pre-expression contributors
expression contribution
post-expression contributors
CubismModel::Update
```

The pre-expression phase is the insertion point for deterministic automatic
blink. The post-expression phase currently retains pose evaluation. No public
scheduler or SDK type was added, and no Render/Graphics/Asset boundary changed.

This corrects the previous single late-update seam: pinned Cubism R5 orders
automatic eye blink before expression evaluation. The existing `AdvancePlayback`
API and result/event behavior remain unchanged until later L2D7 controllers are
introduced.
