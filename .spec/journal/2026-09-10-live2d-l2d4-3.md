# L2D4.3 — Generic submission and unmasked planning

Date: 2026-09-10

## Landed

- Added SDK-free `render::RenderSubmission` values and structural validation.
- Added `RenderSubmissionExecutor`, which prepares frame-local uniform and
  descriptor bindings before applying per-frame buffer writes and recording
  authored pass/draw order.
- Added the Live2D render resource/proxy value boundary and an unmasked
  `Live2DRenderPlanner`. It validates the extracted snapshot, uploads current
  positions, stable-sorts by `(render_order, drawable_index)`, applies visibility
  and empty-range skips, selects blend/culling pipeline handles, and emits
  generic geometry, constants, texture, and indexed draw data.
- Masked drawables fail before publication with an L2D4.4 diagnostic; no
  unmasked approximation is emitted.
- Added focused generic submission and planner tests. Render has no Live2D
  dependency or semantic branch.

## Remaining gate

Native backend Live2D readback and shader/resource creation remain for the
later viewer/resource integration work. The generic executor is compiled into
Render and the planner is compiled into `Live2DRender`, but no Live2D viewer or
main-engine scheduling path is added in this stage. The existing
`GraphicsSmoke` run still exits on the pre-existing D5 silhouette comparator
(`raw=356, edge=293, structural=63, bounds=match`) and reports the known
streaming-geometry/depth-format diagnostics; no new PBR failure was observed.
