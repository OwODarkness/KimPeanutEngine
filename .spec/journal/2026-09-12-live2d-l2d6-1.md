# L2D6.1 typed animation product/import — 2026-09-12

## Investigation

The existing Product V1 layout stored non-Moc/FileReferences data as optional
chunks. That representation could not preserve motion group/index identity,
fade presence, expression display names, parameter groups, or optional motion
sound bytes. The importer also needed to treat expression Name values as data
rather than authored paths.

## Implementation

- Added typed Product V2 records for authored motions, expressions, and
  parameter-target groups.
- Kept the original V1 binary layout readable; V1 parses with empty typed
  vectors and retains its optional chunks.
- Added deterministic V2 serialization/parsing with bounded counts and fields,
  duplicate checks, finite non-negative fade validation, and checked product
  limits.
- Added importer validation for motion/expression JSON, exact file suffixes,
  root containment, names, IDs, and optional sound bytes.
- Excluded Motions and Expressions from the generic optional-chunk walker.
- Deferred native texture publication until source validation and root-product
  serialization succeed.
- Bumped the Live2D import-provider version to 2 without adding Live2D types or
  branches to Asset core.

## Validation

- cmake --build build --config RelWithDebInfo --target Live2DCoreTest --parallel 1
- build/engine/test/unit/live2d/RelWithDebInfo/Live2DCoreTest.exe
- Result: all 19 tests passed, including deterministic Hiyori import, V1/V2
  codec round trip, typed animation fixture import, and existing renderer,
  settings, lifecycle, and AssetManager tests.

## Remaining scope

Runtime clip construction and playback transactions remain L2D6.2/L2D6.3.
The importer preserves motion sound bytes but does not create Audio assets or
choose playback policy.
