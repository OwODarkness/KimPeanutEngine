# Live2D L2D7.4 lifecycle and dependency audit

Date: 2026-09-13

## Objective

Close the L2D7.4 lifecycle/dependency audit by making Product V1/V2/V3 behavior availability explicit at the SDK-free resource boundary, driving the viewer through the canonical frame-update path, and exposing deterministic behavior/lifecycle evidence through the model report and startup capture log.

## Implementation

- Added immutable `Live2DBehaviorCapabilities` derived from Product V1/V2/V3 metadata. V1 reports no typed playback and requires reimport; V2 reports typed playback but no secondary behavior and also requires reimport; V3 reports physics, pose, hit-area, and user-data availability from immutable product chunks.
- Added instance/renderer forwarding and a renderer-side applied behavior mask. `Live2DRenderer::Record` now uses `Live2DModelInstance::AdvanceFrame` with the same neutral viewer input path used by the runtime contract.
- Extended `live2d.model.report` with capabilities, behavior mask, and frame sequence. Startup capture diagnostics now include those fields and continue to report draw/mask/upload counters.
- Added Product V1/V2/V3 capability assertions to the Live2D product round-trip test.

## Ownership and remaining scope

Capability data remains immutable resource metadata. Mutable parameters, behavior execution, frame sequencing, and applied masks remain instance/renderer-owned; GPU resources remain renderer/RHI-owned. L2D7.5 interactive debug controls remain a separate planned stage and are intentionally not folded into this audit.
## Follow-up correction: cross-backend uniform layout

The masked drawable regression was traced to shader uniform blocks omitting an explicit `std140` layout qualifier. OpenGL could therefore place `model_to_atlas_sample` using a packed offset while Vulkan used the expected 128-byte-aligned offset. All Live2D color, mask, and masked shader blocks now declare `layout(std140, binding = 0)`, and CPU compile-time assertions cover the 72/80-byte mask-source block and 128/192/208-byte masked block offsets.

The corrected OpenGL and Vulkan viewer captures are `save/screenshots/validation/l2d7-4-layout-opengl.png` and `save/screenshots/validation/l2d7-4-layout-vulkan.png`; both completed with clean Cubism shutdown.

The follow-up also adds an explicit KPENGINE_LIVE2D_OPENGL shader define and flips only the OpenGL masked-draw V coordinate; Vulkan retains its native atlas orientation. The corrected captures differ only by negligible backend rasterization noise (mean RGB delta approximately 4.7e-5).
