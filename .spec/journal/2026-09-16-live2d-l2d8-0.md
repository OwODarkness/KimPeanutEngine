# Live2D L2D8.0 — Semantic vocabulary and authored bindings

- Status: complete
- Date: 2026-09-16
- Plan: [L2D8](../../docs/live2d/.plan/L2D8.md) · Roadmap:
  [TODO](../../docs/live2d/TODO.md)

## Objective

Define the first semantic emotion/body-language contract above L2D6 playback
and L2D7 secondary behavior without coupling the public API to Cubism, Render,
or viewer code.

## Implementation

- Added `Live2DEmotionPolicy` with a schema version, semantic states, authored
  motion/expression bindings, and an explicit idle fallback state.
- Added SDK-free lookup helpers for states and bindings.
- Added validation against typed Product V2/V3 motion and expression data. The
  validator rejects unsupported schema versions, invalid or duplicate states,
  non-idle fallbacks, incomplete bindings, old products, and missing authored
  references with stable diagnostics.
- Kept policy data separate from immutable product data and deferred priority,
  interruption, blending, and runtime selection to L2D8.1.
- Added the contract as part of `Live2DProduct`, so SDK-off builds can consume
  and test it independently.

## Remaining scope

L2D8.0 does not select behaviors at runtime or publish state transitions. Those
belong to L2D8.1 and L2D8.2 respectively. No renderer, viewer, or asset-core
semantic branch was added.
