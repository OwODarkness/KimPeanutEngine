# Audio M1.3 — bounded native playback

Date: 2026-10-02

## Outcome

Added a file-backed `.audio` runtime loader and a seekable `AudioPlayer` for
native music products. Product parsing reads the directory and bounded
metadata chunks, then verifies the full product digest with a fixed 64 KiB
hash buffer; it does not copy encoded music into `AudioResource`. The source
descriptor carries the encoded range and a shared product lifetime pin.

`SeekableAudioPlayer` owns a decode worker and miniaudio range decoder. The
worker decodes to 48 kHz stereo float in 1,024-frame chunks and maintains a
fixed 96,000-frame cache (two seconds) plus 1,024-frame scratch. Audio callback
mixing only try-locks this cache, copies/interpolates samples, and advances the
played-frame clock for consumed frames. Missing data buffers without advancing
the clock. Seek invalidates old cache contents; pause, loop, 0.5×–2.0× playback
rate, and subtitle lookups share the played-frame timeline.

The `AssetManager` recognizes `.audio` and returns metadata, waveform, and
subtitle cues in `AudioResource::native_product`. `SubtitleTextAt(frame)`
queries half-open cue intervals for presentation use. The raw WAV/MP3/FLAC
loader remains available as the compatibility preview path. The standalone
Editor player has not migrated to native products; that work belongs to
M1.4.

## Validation

- `cmake --build build --config Debug` — passed, including the Runtime,
  Editor, AssetTool, engine, and unit-test targets.
- `ctest --test-dir build -C Debug -R "Audio|NativeAudioRuntimeTest"
  --output-on-failure` — passed 40/40.
- `ctest --test-dir build -C Debug --output-on-failure` — 1,109/1,114 passed.
  The five failures reproduce in a focused rerun and are outside this change:
  four `AssetCatalogProviderTest` assertions expect Partial/archive-unavailable
  data but receive an empty snapshot; `TerrainMeshTest` expects 24 indices but
  receives 96. No files in those test implementations were changed.
- Offline playback fixture duration is 60 seconds while the PCM cache holds
  only two seconds. The test verifies emitted samples, playback cursor, pause,
  seek, 2× rate, loop wrap near end, cue boundaries, and fixed memory bound.
  A separate lifetime test verifies the native product stays alive through
  player destruction.

## Remaining work and risks

- M1.4 must connect the native product to the standalone player, expose import
  and subtitle state, and verify audible playback in a visible device session.
- Native product seek/playback has an automated 60-second WAV fixture. Runtime
  codec seek acceptance for imported MP3/FLAC and visible device playback are
  not established by this stage.
- OGG remains unsupported by the current miniaudio build, as recorded in M1.1.
- The full suite retains the five baseline failures listed above.
