# L2D4.0 — Render contract and conformance freeze

## Objective

Freeze the CPU-visible color, alpha, masking, coordinate, tolerance, and
feature-policy contracts before L2D4.1–L2D4.4 add Graphics and shaders.

## Design boundary

`engine/module/live2d/render/live2d_render_contract.*` contains only value
types and pure CPU functions. It includes no Cubism, Graphics backend, Asset,
OpenGL, or Vulkan type. Static extraction will populate
`Live2DRenderFeatureReport`; later renderer stages consume its validation
result before publishing GPU resources.

## Reference gate

The configured external SDK is Cubism 5 Native R5 at
`D:/library/CubismSdkForNative-5-r.5`. The Framework release is recorded as
`5-r.5` in `Framework/CHANGELOG.md` (2026-04-02), and the existing lifecycle
test reports `sdk_version == "5-r.5"`. The Core package is the matching local
package selected by `build-live2d/CMakeCache.txt`.

The pinned official Framework, OpenGL, and Vulkan sources were inspected
locally. The official repository references remain:

- [Framework renderer](https://github.com/Live2D/CubismNativeFramework/blob/145155d2c5bdd8d23475cef9cc3ab46d3220190c/src/Rendering/CubismRenderer.cpp)
- [OpenGL renderer](https://github.com/Live2D/CubismNativeFramework/blob/145155d2c5bdd8d23475cef9cc3ab46d3220190c/src/Rendering/OpenGL/CubismRenderer_OpenGLES2.cpp)

No renderer source was copied. The two backends agree on the observable
compatible-mode and mask equations used below; backend-native resource and
command ownership remains outside this contract.

## Frozen decision table

| Concern | V1 contract | Evidence / consequence |
| --- | --- | --- |
| Source texture | RGBA8 sRGB color texture; RGB is decoded to linear on sampling, alpha is unchanged | Existing TextureData uses `TEXTURE_FORMAT_RGBA8_SRGB`; shader math is performed after sampling |
| Shader math / output | Straight-alpha linear sample → multiply RGB → screen RGB → opacity/mask → premultiplied linear RGBA | Matches the R5 normal/masked shader structure; the RHI target performs final sRGB encoding |
| Color modifiers | `t' = t * multiply + screen - t * multiply * screen` per RGB channel | Same order as official R5 standard shaders; screen alpha is not used |
| Normal blend | `out = src + dst * (1 - src.a)` for RGBA | PMA `(ONE, ONE_MINUS_SRC_ALPHA)` color and alpha factors |
| Additive blend | `out.rgb = src.rgb + dst.rgb`, `out.a = dst.a` | Compatible `(ONE, ONE)` RGB and `(ZERO, ONE)` alpha factors |
| Multiplicative blend | `out.rgb = src.rgb * dst.rgb + dst.rgb * (1 - src.a)`, `out.a = dst.a` | Compatible `(DST_COLOR, ONE_MINUS_SRC_ALPHA)` RGB and `(ZERO, ONE)` alpha factors |
| Accepted drawable modes | Normal, compatible Add, compatible Multiply | Advanced R5 color/alpha modes and unknown values are rejected; no approximation |
| Render order | Stable ascending render order; equal values retain ascending drawable index | Avoids the official array-overwrite ambiguity for equal orders and makes the engine deterministic |
| Culling | Drawable culling is a per-drawable raster state; no CPU winding rewrite | OpenGL and Vulkan use CCW front faces for Cubism geometry; backends translate their native orientation |
| Mask storage | One 256×256 linear RGBA8_UNORM atlas, cleared to `(1,1,1,1)`; channels are R,G,B,A | R5 mask pass stores inverse coverage with `dst *= 1 - src`; model sampling resolves ordinary coverage as `1 - stored`, inverted as `stored` |
| Mask packing | Channel-then-region order; each channel uses one full region, two horizontal regions, 2×2 for 3–4 regions, or 3×3 for 5–9 regions as required | Official layout algorithm; fixed V1 capacity is 4×9 = 36 active contexts |
| Mask margin | 5% of the clipped draw bounds in both dimensions | Official Framework expands bounds before deriving mask matrices |
| Coordinates | Model space is y-up; atlas layout is logical bottom-left; vertex UVs use authored `v` with the backend shader’s single y conversion | Vulkan flips NDC y; both official paths flip texture-coordinate y at the shader boundary |
| Numeric policy | CPU equation tolerance `1e-5`; non-edge backend parity `2/255`; filtered mask edge `4/255` per channel | Tolerances cover float arithmetic and normalized readback without hiding broad parity errors |
| Transparent RGB | If alpha ≤ `1e-5`, comparison RGB is canonicalized to zero | Prevents undefined RGB in invisible pixels from failing parity; PMA output already produces zero RGB for zero alpha |
| Unsupported features | Offscreen objects, blend groups, topology changes, invalid indices, unknown blend modes, and >36 active contexts fail before GPU publication | `Live2DRenderFeatureReport` returns machine-readable issue codes and stable diagnostics |

## Fixture and licensing

The configured external Wanko fixture is present at the SDK path and contains
`Wanko.moc3` (107456 bytes) plus its model metadata. The SDK license identifies
Wanko as a Free Material model and requires agreement to the model terms. The
fixture is not copied into this repository and is not used as a CI golden.

No official OpenGL/Vulkan sample executable is present under the external SDK
sample tree, so an official R5 still could not be captured in this workspace.
This is an explicit access/licensing blocker, not a rendering-policy gap.
The SDK shader/source inspection and synthetic CPU cases are the current
conformance evidence. L2D5 must replace this blocker with an approved fixture,
capture metadata, and a final cross-backend image comparison before V1 release.

## Landed

- Added `Live2DColor`, V1 blend equations, inverse-mask resolution, transparent
  RGB canonicalization, comparison tolerances, and packed-atlas constants.
- Added `Live2DRenderFeatureReport`, issue codes, deterministic validation order,
  and stable diagnostics for every L2D4 V1 rejection path.
- Added the SDK-free `Live2DRenderContractTest` with hand-computed zero/partial
  alpha, multiply/screen, normal/additive/multiplicative, ordinary/inverted
  mask, transparent RGB, capacity, and multi-issue cases.
- Wired the contract test into SDK-on and SDK-off CMake configurations without
  making the test link against Cubism.
