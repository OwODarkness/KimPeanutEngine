# L2D7.1 Product V3 Import — 2026-09-13

- Status: implementation baseline; L2D7.2–L2D7.4 remain ordered follow-up work.
- Scope: add typed immutable secondary behavior data to the native Live2D
  product and import it transactionally from model3 package references.

## What landed

Product V3 extends the SDK-free `Live2DProductData` value with:

- bounded Physics and Pose JSON bytes;
- ordered, unique hit-area names and drawable IDs; and
- ordered immutable UserData target/value entries.

The codec keeps Product V1 and V2 binary layouts readable and appends the V3
header counts and behavior payload only for version 3. It validates collection
and field bounds, duplicate hit-area names, required strings, NUL bytes, and
trailing data before accepting a product.

The importer deliberately consumes `FileReferences.Physics`, `Pose`, and
`UserData`, plus top-level `HitAreas`. Physics and Pose retain their exact
validated JSON bytes for the pinned Cubism Framework; UserData is structurally
validated and normalized into SDK-free values. Those references are excluded
from generic optional-chunk discovery. The local resource is fully built before
it is returned, so a malformed secondary file cannot publish a partial product
or cooked-texture root.

Runtime construction reads typed Product V3 Pose bytes first and retains the
legacy Product V1/V2 `Pose` optional-chunk fallback. No Render, Graphics, Asset
core, or backend API changed.
