# Live2D L2D7.5 — Runtime Debug Tools

Date: 2026-09-13

## Objective

Add viewer-only controls for normalized gaze input, pause/resume, single-frame
stepping, parameter reset, and copied behavior diagnostics without coupling the
Live2D runtime to ImGui or window input types.

## Implementation

- `Live2DViewerHost` now owns Neutral, Follow Mouse, and Fixed Target gaze modes,
  converts the viewer image rectangle and cursor position into finite `[-1, 1]`
  `Live2DFrameInput::gaze_target` values, and exposes pause/resume/step/reset
  controls in the existing profiler panel.
- `Live2DRenderer` accepts an explicit frame input and an `advance_frame` flag;
  paused frames render the current model without advancing `update_sequence`,
  while Step One Frame advances exactly one `AdvanceFrame` transaction.
- `Live2DModelInstance` stores its initial parameter values and exposes a
  viewer-safe `ResetParameters()` operation. Runtime behavior remains instance-
  owned and SDK/UI-free.
- The debug panel reports gaze target, behavior mask, update/snapshot sequence,
  parameter and drawable counts, hit-area/user-data availability, and secondary
  behavior availability.

## Ownership and remaining scope

Tool state remains viewer-owned. Runtime receives only copied value input and owns
behavior mathematics. No Asset, Render, Graphics, Editor, or deferred/PBR path
was given an L2D7.5 semantic branch. State-machine graphs, emotion policy, and
persistent tool settings remain L2D8/L2D10 work.
## Control deck UI refinement

- `Live2DViewerHost` now renders an isolated `Live2D Control Deck` beside the
  viewer. Gaze, Playback, and Telemetry are separated into tabs so controls do
  not compete with frame metrics.
- The profiler is metrics-only and is stacked below the control deck. Both
  panels use a scoped dark-violet, cyan, and magenta theme with rounded cards,
  compact headers, and behavior status chips; no runtime ownership changes.
- OpenGL and Vulkan window captures were rerun after the layout change:
  `save/screenshots/validation/l2d7-5-control-deck-opengl.png` and
  `save/screenshots/validation/l2d7-5-control-deck-vulkan.png`.
