# L2D4.2 SDK-free model extraction journal

## 2026-09-10

- Added SDK-free `Live2DStaticModelData`, `Live2DDrawableStatic`,
  `Live2DMaskContext`, `Live2DDrawableState`, and `Live2DFrameSnapshot` value
  contracts under the Live2D runtime module.
- Added one-time Cubism extraction of canvas metadata, concatenated UVs and
  UInt16 local indices, drawable ranges, canonical equal mask-source contexts,
  feature counts, and a deterministic topology revision.
- Added per-instance ordered `shared_ptr<const asset::TextureResource>`
  retention. Instance creation rejects missing, non-texture, null, or
  count-mismatched dependencies before exposing the instance.
- Added atomic frame extraction: all current drawable positions and state are
  copied into local vectors, validated against the static revision, and swapped
  into the caller only on success. Cubism types remain private to the `.cpp`.
- Rejected unsupported offscreen/blend-group features, invalid local indices,
  unsupported blend modes, non-finite canvas/UV/position/color/state values,
  stale revisions, and inconsistent ranges with diagnostics.
- Added an SDK-free model-data contract test and extended the imported Hiyori
  test for two-instance isolation, deterministic topology, frame deformation,
  texture retention, sequence monotonicity, and post-Asset-wrapper lifetime.
