# Live2D L2D8.2 — Runtime observability

- Status: complete
- Date: 2026-09-16
- Plan: [L2D8](../../docs/live2d/.plan/L2D8.md) · Roadmap:
  [TODO](../../docs/live2d/TODO.md)

## Objective

Make the L2D8.1 semantic resolver inspectable without exposing Cubism, Render,
Graphics, or viewer types. Callers need the current semantic behavior, the
authored motion/expression references selected for it, and a bounded record of
how the resolver reached the current state.

## Implementation

- Added `Live2DBehaviorSnapshot` with copied state ID, authored motion and
  expression references, priority, transition sequence, blend mode, reason,
  active flag, and terminal state.
- Added `Live2DBehaviorTransitionRecord` and a fixed logical history capacity of
  `kLive2DEmotionTransitionHistoryCapacity` (32 records). Records are value-owned
  and contain no SDK pointer or callback.
- Added `CompleteActive` and `CancelActive` for the L2D6 execution boundary to
  publish terminal results. Replacing an active behavior records the old one as
  `Interrupted` before the new behavior becomes active.
- Kept rejected lower-priority and same-state requests out of transition
  history: they are request resolutions, not semantic transitions, and retain
  the current state without changing its terminal result.
- Reset clears the current observation and bounded history, preserving the
  resolver's instance-local ownership model.

## Validation

- `cmake --build build --config Debug --target Live2DEmotionPolicyTest Live2DProduct --parallel 1` — passed.
- `ctest --test-dir build -C Debug -R 'Live2DEmotion' --output-on-failure` — 9/9 passed.
- `ctest --test-dir build -C Debug -R 'Live2D' --output-on-failure` — 65/65 passed.
- SDK-off `Live2DEmotionPolicyTest` build and direct execution — 9/9 passed.
- New tests cover copied snapshots, completion, cancellation, interruption,
  monotonic record ordering, and history capping.

## Remaining scope

L2D8.2 does not add a viewer panel or scripted OpenGL/Vulkan replay. L2D8.3
owns that diagnostic presentation and cross-backend evidence.
