# Live2D L2D7.2 — Instance Secondary Behavior

- Date: 2026-09-13
- Plan: [L2D7](../../docs/live2d/.plan/L2D7.md)
- Scope: instance-local behavior configuration and canonical frame update

## Result

Implemented the first runtime secondary-behavior layer without exposing Cubism
SDK types or changing Render/Graphics ownership. `Live2DSystem` accepts an
optional `Live2DSecondaryBehaviorConfig`; the existing one-argument factory
keeps its compatibility defaults.

`Live2DModelInstance::AdvanceFrame` now validates all value inputs before state
mutation and runs one ordered transaction: parameter checkpoint, direct writes,
primary motion, checkpoint save, deterministic engine-owned blink, expression,
gaze, breath, physics, pose, one Cubism model update, then result publication.
`AdvancePlayback` remains a wrapper over this path, so existing callers retain
their API and event behavior.

The implementation uses the imported Product V3 physics/pose bytes, authored
EyeBlink parameter groups, and conventional Cubism breath/look mappings. Each
controller and its mutable state belongs to one model instance. Missing
optional conventional channels are treated as no-op behavior; malformed physics
or invalid behavior configuration rejects instance creation with a diagnostic.
