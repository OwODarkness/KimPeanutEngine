# R5.4 implementation — 2026-09-29

Moved `PerPassData` and `PerObjectData` from common Graphics into
`render/render_shader_data.h`. The existing `CameraData` stays in Render.
Compile-time assertions preserve the structures' matrix composition, member
offsets, sizes, and alignment relationships. Render source and the direct RHI
example now refer to Render-owned schemas.

Removed the Render-specific profile pass count from `RenderBackend`. Render
registers stable IDs derived from canonical pass names before backend init;
Graphics rejects duplicate IDs and registration beyond its generic capacity.
Vulkan and OpenGL allocate query slots from the registered set and return the
original IDs with timings. Their skipped-pass handling remains slot-based.

Source audit: Vulkan AS resources, descriptor sets, and address tables retire by
completed submission serial, with address tables also retained while referenced
by descriptor sets. `DeferredRenderer::Cleanup` waits idle before destroying the
path-tracing pipeline and SBT. `EnsureHistoryTargets` also waits idle before
replacing history resources. The R5.4 decision is to retain immediate pipeline
destruction at this idle boundary and not split private owners based on source
inspection alone.
