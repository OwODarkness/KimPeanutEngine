# P2 — Offscreen Render and Cross-Backend Capture

## Goal

Make the panel visible for the first time: content to GPU to image, ending in a
cross-backend capture. P0 and P1 produced a representation and real glyphs but
nothing drew them; `ToAsciiArt` was the only way to see any output.

This is deliberately *not* world placement. It produces an offscreen target and
a PNG, the way Live2D progressed in L2D4. Camera and scene integration are a
later stage.

## Scope

In:

- a single-channel texture payload path, so a dot mask can be uploaded;
- a submission planner and a GPU-owning renderer for the panel;
- a standalone `panel-viewer` application mode that renders offscreen and
  captures;
- runtime commands so a run can report what it loaded and change its text.

Out:

- world-space placement, camera, scene integration;
- animation, effects, named patterns, per-character colour;
- Asset-system registration — deferred while the only consumer is the host,
  which reads the product directly.

## Decisions

| Question | Decision |
| --- | --- |
| Output | Offscreen render target plus PNG capture. |
| Colour | One uniform for every dot. Default white on black, because both are fixed points of the sRGB encode, so a capture proves the dot pattern without also depending on the target format. |
| Ownership | The panel gets its own application mode. It must not be loaded by the Live2D viewer, and Live2D must not gain a panel dependency. |
| Dot mask format | Fix `BytesPerPixel` so `R8_UNORM` with a payload validates. |
| Shaders | Tracked through `.gitignore` exceptions, following that file's own convention. |

## Design

**One quad, one texture.** The generic submission contract permits indexed,
non-instanced draws only, so a quad per character cell is out of contract. The
panel draws one quad sampling a dot mask; the dot-to-pixel expansion is NEAREST
sampling rather than arithmetic. See [PLANS.md](../PLANS.md#rendering).

**Static geometry.** Four clip-space positions and six `UInt16` indices, both
immutable and uploaded at creation. Immutable buffers cannot be written through
the submission's `buffer_writes`, so nothing is uploaded per frame at all.

**Recreate, do not update.** The backend exposes no in-place texture upload, so a
content change recreates the mask: create the replacement, `WaitIdle`, then
release the previous handle.

**Fail whole.** The planner validates the submission before publishing and
publishes nothing on failure, so a caller can never record half a panel.

## Acceptance

- [x] An `R8_UNORM` texture with a correctly-sized payload validates; a
      wrong-sized one still fails; the allocation-only path is unchanged.
- [x] The planner emits exactly one target pass with one quad draw, binds both
      descriptors at set zero, and publishes nothing when any input is missing.
- [x] The renderer mints every handle, releases the replaced mask only after
      `WaitIdle`, keeps its previous target when a resize fails, and reports zero
      live handles after cleanup.
- [x] `panel-viewer` renders and captures on both OpenGL and Vulkan.
- [x] Captures from the two backends are byte-identical.
- [x] The capture decodes to the expected dot pattern, upright and unmirrored.

## Validation

See the journal for commands and output. The strongest check is pixel-level: the
panel draws a known `DotMatrix`, so the capture can be decoded back to dots and
compared against what the layout says should be there. That validates glyph
bake, layout, upload, sampling, orientation, and draw order in one assertion.

## Known limitations

- **Outline rasterisation at 16x16.** Legible for common characters; ASCII
  strokes thicken. A hand-tuned bitmap font would be crisper and does not change
  the product format.
- **The product is local.** It is derived from a licensed Windows font, lives in
  the git-ignored `asset/` tree, and is reproducible only on a machine with that
  face.
- **`--capture-view live2d`** is the spelling for the product view. It is now a
  misnomer for a panel run; a neutral spelling would touch Live2D's documented
  surface, so it has not been added.
