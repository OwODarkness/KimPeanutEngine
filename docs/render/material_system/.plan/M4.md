# M4 — Frame-local material bindings

Parent: [Material System plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

`FrameContext` packs persistent material values into per-frame uniform ranges
and creates transient resource-binding sets. A material instance may request
bindings but must not cache a frame-local handle across frame-slot retirement.

Acceptance: normal reuse, resize, teardown, and rejected post-retirement
binding reuse pass on Vulkan and OpenGL.

Status: complete.
