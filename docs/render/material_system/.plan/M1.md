# M1 — Handles and immutable templates

Parent: [Material System plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Define generational `MaterialTemplateHandle` and `MaterialInstanceHandle`
values plus immutable template descriptions. Template state contains shader
identity, surface policy, parameter layout, defaults, and pass compatibility;
it owns no native API object or World pointer.

Acceptance: stale/forged handles, duplicate/destroy behavior, immutable
description ownership, and template lifetime rejection are covered headlessly.

Status: complete.
