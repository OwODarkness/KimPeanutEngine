# M2 — Instances and parameter validation

Parent: [Material System plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Instances select a template and store sparse typed overrides. Parameter names
resolve to compact IDs at template creation; values are scalar, vector/color,
or API-neutral texture/sampler references. Missing values use template
defaults, and unknown IDs, type mismatches, and invalid logical references are
rejected.

Acceptance: defaults, sparse overrides, type validation, shared-template
lifetime, and stale instance handles are covered headlessly.

Status: complete.
