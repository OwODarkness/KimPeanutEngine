# M6 — Material Asset V1

Parent: [Material System plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Asset owns versioned declarative `*.material` data: shader reference, surface
policy, and typed defaults/texture asset references. Gameplay publishes only
the material `AssetID`; Render resolves one private template/default-instance
pair per material asset and retains readiness diagnostics.

Acceptance: valid and malformed assets, unsupported versions, unloaded or
broken dependencies, deduplication, pending/failed states, and AssetID-only
Gameplay-to-Render flow are tested.

Status: complete (2026-08-28). See the
[material journal](../../../../.spec/journal/render-material-system-v1.md).
