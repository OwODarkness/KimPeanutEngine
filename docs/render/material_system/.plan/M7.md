# M7 — Pass-specific material expansion

Parent: [Material System plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Add pass-specific material semantics only when a consumer requires them. PBR
G-buffer, lighting, shadow, and post-process policy belongs to the Deferred PBR
submodule; Material System should expose stable material intent and compatible
pass declarations without absorbing renderer scheduling.

Acceptance: any new pass compatibility preserves Asset → Resource → Render
ownership, frame-local binding lifetime, and common API neutrality.

Status: open.
