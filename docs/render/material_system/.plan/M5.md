# M5 — MeshProxy and draw-list integration

Parent: [Material System plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

`MeshProxy` stores the logical material instance identity. Draw-list building
rejects unready mesh/material combinations and sorts opaque work by resolved
pipeline, material instance, and mesh. Transparent candidates remain separate
until camera-depth sorting is designed.

Acceptance: a registered proxy renders through a ready material without a
World-to-Graphics dependency or backend-native material object.

Status: complete.
