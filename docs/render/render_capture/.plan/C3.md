# C3 — Vulkan and OpenGL implementations

Parent: [Render Capture plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Implement the common readback contract privately in Vulkan and OpenGL. Both
backends publish the same tightly packed RGBA8 `CapturedImage`; API-specific
image copies, layout/state transitions, synchronization, and pixel-origin
normalization remain below Graphics.

Acceptance: both backends capture the same Render-owned SceneColor target and
survive resize and teardown without reading a recycled attachment.

Status: complete.
