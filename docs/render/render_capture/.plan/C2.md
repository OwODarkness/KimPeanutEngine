# C2 — Common-RHI readback contract

Parent: [Render Capture plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Graphics exposes only the narrow operation needed to read a completed color
attachment into owned CPU image data. Attachment access, transitions, staging,
row-pitch normalization, synchronization, and retirement remain Graphics
responsibilities; native types do not cross the boundary.

Acceptance: readback pins the source generation through completion and fails
explicitly during invalid format, resize, or shutdown conditions.

Status: complete.
