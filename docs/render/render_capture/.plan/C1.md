# C1 — Capture service and pixel callback policy

Parent: [Render Capture plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Define `IRenderCaptureService` as a semantic, callback-based API returning
owned `CapturedImage` pixels. Render owns request state and view selection;
Runtime owns paths and export; Graphics is not exposed through the public API.

Acceptance: one pending request is accepted/rejected explicitly, unsupported
views complete with `Unavailable`, and completion fires exactly once.

Status: complete.
