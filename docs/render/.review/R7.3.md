# R7.3 review — native-resolution TAA

Initial review: 2026-10-13. Acceptance: **2026-10-22, complete**.
Baseline: `699ac30` plus the preserved R7.3 working tree and separate stable
Scene3D startup repair. Scope: [R7.3](../.plan/R7.md#r73--native-resolution-temporal-anti-aliasing),
Render-owned raster TAA, submitted history, and Vulkan/OpenGL execution.
R5/R6 acceptance, PT reconstruction, fog, and focused R7.1 acceptance remain separate.

## Findings and resolution

1. **P1 — jitter/reconstruction: resolved.** GBuffer motion removes projection
   jitter. The resolve reconstructs current HDR into the stable output grid
   using current jitter once; stable-grid history uses unjittered motion once.
   The delivered uniform and both APIs' matched reference comparisons pass.
2. **P1 — previous-frame depth: resolved.** GBuffer normal alpha carries the
   current surface's expected previous-view depth; history metadata retains
   current depth. Camera and rigid-object replay, cut recovery, and reference
   comparisons pass. Shading-normal validation now checks the same identity's
   depth-bounded 3×3 normal footprint, preserving normal-mapped detail without
   relaxing the original 0.85 agreement threshold across unrelated surfaces.
3. **P1 — fullscreen orientation: resolved for current outputs.** Color/history
   and GBuffer guides use explicit coordinate conventions. Both APIs' on/off
   scene and full composited-window captures are upright. The earlier OpenGL
   upside-down report does not reproduce with this code.
4. **P2 — immutable shader publication: resolved.** Replacement creation
   precedes retirement; failure retains the old pipeline/history. Successful
   publication waits safely and invalidates history. Owner tests cover success,
   rejection, pending-history cancellation, and submitted-only rotation.
5. **P2 — storage evidence: resolved.** Each history pixel uses 16 bytes
   (RGBA16F color, RGBA8 packed octahedral normal/log depth, RGBA8 identity).
   At 1094×631, active R7 payload is 31,754,444 bytes (30.28 MiB) and Vulkan
   allocation ranges total 32,440,320 bytes (30.94 MiB), below 32 MiB.
   OpenGL allocation measurement is unsupported and stays absent.
6. **P2 — lifecycle coverage: resolved.** Tests and runtime cover rejected
   submission, failed target allocation, resize retirement, idempotent cleanup,
   cut/resize/minimize/restore/reload, and PT exclusion/history preservation.
   Temporal target/pipeline preparation now precedes frame recording. Vulkan
   `WaitIdle` cannot assign submitted serials to the active frame's AS scratch;
   this fixes the reproduced UI-resize destruction/invalid-command-buffer path.
7. **Quality acceptance: resolved.** YCoCg bounds, edge-clamped reconstruction,
   same-surface normal rejection, and an active-TAA-only half-mip texture bias
   pass the fixed gates below. Eight Vulkan TAA-off pose captures remain
   byte-identical to the pre-correction baseline. PT sampling/filtering is unchanged.
8. **Smoke fixture drift: resolved.** GraphicsSmoke reuses the current owned
   GBuffer and supplies the existing SSAO/tone-map descriptors/options. Both
   APIs pass six frames; the Vulkan run has no validation VUIDs.

Identity is a byte-exact 32-bit renderable ID+1. Generations participate in the
whole-scene signature and submitted transform history, invalidating recycled
handles. Sky/invalid surfaces bootstrap from current color; selection/UI remain
downstream. Resource processing, GPU ownership, and module dependencies are unchanged.

## Frozen quality gates

Validation uses camera-matched canonical Sponza outputs plus a 2× render reduced
offline in linear display color as reference. The same camera poses, lights,
exposure, complete residency, and native extent are required. SSAO and ray-query
noise are disabled for isolated quality comparisons, then enabled for combined
budget validation.

- Static reference mean absolute error with TAA must not exceed TAA-off.
- Motion error shimmer over the frozen subpixel camera poses must decrease by
  at least 20% versus TAA-off.
- Reference edge-gradient error must not exceed TAA-off by more than 10%.
- Newly revealed rigid-object/background surfaces must reject stale history;
  cut/resize/mode changes must invalidate history and recover after submitted
  current-color bootstrap. No full-scene trails are acceptable on inspection.
- TAA resolve GPU p95 ≤1.0 ms; combined raster GPU p95 ≤8.5 ms; active R7
  texture storage ≤32 MiB at the frozen 1094×631 extent.


## Acceptance results

| Metric | Vulkan off → on | OpenGL off → on |
| --- | --- | --- |
| Static reference MAE | 0.018285 → 0.013119 (−28.25%) | 0.018246 → 0.012836 (−29.65%) |
| Pose-sequence error shimmer | 0.020642 → 0.013332 (−35.42%) | 0.020602 → 0.013326 (−35.32%) |
| Edge-gradient error | 0.045358 → 0.029836 (−34.22%) | 0.045257 → 0.029859 (−34.02%) |

The fixture, poses, 16 settling frames, and numeric thresholds are unchanged.
R7.3 uses history weight 0.9. Reference size is exactly 2188×1262, reduced
offline in linear display color. Rigid-move/return inspection shows no full-scene
trails. The quality gate is this frozen pose sequence, not a universal temporal
image-quality guarantee for arbitrary scenes or unsupported deforming geometry.

Three uncontended RelWithDebInfo Vulkan windows, each 120 warm-up/300 samples,
use canonical textured Sponza, 1094×631, complete residency, Medium AO, PT off,
and hybrid ray-query shadows on. TAA p95 is 0.099328/0.102400/0.101376 ms;
total GPU p95 is 3.215283/3.339662/3.325155 ms. Memory is 30.94 MiB throughout.
Device: RTX 4070 Laptop GPU, driver 617.42. Debug Vulkan correctness retains
normal validation; performance uses the normal RelWithDebInfo configuration.

251/251 Render/Graphics contracts pass. Broad Debug validation initially had
14 external failures; after fixing five Render test callers for pre-frame
preparation, the recheck leaves nine unrelated Asset/Terrain failures. These
are not counted as passing or as R7/R5/R6-wide acceptance.
