# R4.1 review — graph correctness prerequisites

## Status

Complete. The review authorizes R4.2 Graphics RT contract work, subject to the
R4.2 scope and ownership review.

## Scope reviewed

- graph write/update dependency construction;
- required texture and buffer state execution;
- frame-local logical-to-physical raster bindings;
- propagation through `DeferredRenderer` and `RenderSystem`;
- common-contract ownership and backend translation.

## Findings

1. **Resolved — preserving writes now retain producer lineage.** The compiler
   adds an edge from the previous version's producer for `None`/`Load` writes;
   `Clear` is explicit discard. This covers write-after-write and
   read-modify-write flows without making the fluent SSA API implicit.
2. **Resolved — physical resolution no longer uses raster ordinals during
   execution.** `DeferredRenderer` builds an exact-handle frame table from
   compiled lifetimes after transient acquisition. Missing names or handles
   fail before a pass records.
3. **Resolved — state failures are observable.** Texture requirements return
   their backend result, buffer requirements call the common recorder seam,
   and required recording failure reaches `DeferredRendererFrameResult` and
   `RenderGraphFrame` without breaking the existing recoverable frame bracket.
   External terminal requirement failure makes frame finalization fail.
4. **Resolved — common boundary remains API-neutral.** The new buffer method
   carries `BufferHandle` and `ResourceUsage` only. Vulkan emits a native
   buffer barrier below the boundary; OpenGL relies on implicit ordering.
5. **Open for later stages — graph buffer providers.** The current deferred
   raster graph has no logical buffer resources, so the frame table rejects a
   future graph buffer until its owner/provider is introduced with R4.2/R4.3.
   This prevents a silent fake binding while keeping buffer intents executable.

## Evidence inspected

- R4.1 spec and R4 plan/TODO acceptance ledger.
- `render_graph.cpp`, `deferred_renderer.cpp`, `render_system.cpp`.
- Common, Vulkan, and OpenGL command-recorder contracts.
- Focused graph, render-system, graphics-contract, and smoke validation.

## Decision

R4.1 is accepted. The implementation is sufficient to prevent the current
raster graph from hiding update dependencies, physical binding failures, or
buffer state intents. RT resource vocabulary remains deferred to R4.2/R4.3.
