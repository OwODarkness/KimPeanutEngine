## Findings and decisions

1. **Resolved — handle scope.** Texture, buffer, and pass handles carry a
   monotonic graph identity plus local index/version. Cross-graph and invalid
   handles produce deterministic diagnostics.
2. **Resolved — version semantics.** A write returns a new version; imported
   resources expose an externally produced version zero; transient version zero
   has no producer and cannot be read.
3. **Resolved — roots and culling.** Exports and enabled side-effect passes are
   roots. Reverse dependency reachability retains their producers; unreachable
   enabled passes and disabled optional passes are omitted.
4. **Resolved — deterministic order.** Resource-flow and explicit dependency
   edges feed a Kahn topological sort whose ready queue is declaration index.
   Cycles and enabled-to-disabled conditional dependencies are rejected.
5. **Resolved — ownership.** The graph stores logical declarations and
   intervals only. Graphics remains the owner of physical resources, native
   synchronization, command recording, and retirement.
6. **Resolved — migration boundary.** R3.2 does not express the fixed eight
   passes or change runtime recording. R3.3 remains the compatibility proof
   gate, and R3.4+ remain separately scoped.

## Review conclusion

No blocking design finding remains for the R3.2 pure compiler. The user
authorized implementation on 2026-09-17; this review authorizes only the R3.2
CPU-only boundary described above, not runtime graph execution or backend
changes.
