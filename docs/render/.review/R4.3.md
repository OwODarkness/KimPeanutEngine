# R4.3 graph/import review

- Status: graph slice accepted; native owner follow-up remains open
- Stage: [R4](../.plan/R4.md)
- Review date: 2026-09-19

## Decisions

1. **Logical AS is a third graph resource kind.** It uses the same graph ID,
   version, reachability, lifetime, and transition machinery as textures and
   buffers without exposing a native handle.
2. **TLAS import is explicit and frame-local.** The plan names `SceneTLAS`; the
   renderer resolves that name to a borrowed Graphics handle for the current
   frame and rejects a missing binding.
3. **Fallback is structural.** The ray-query plan variant is selected only by
   effective capabilities plus a valid TLAS. OpenGL and incomplete Vulkan stay
   on the existing shadow-map variant.
4. **Build scheduling is deferred.** No graph pass creates or builds an AS in
   R4.3; that avoids claiming a native owner that is not yet complete.
