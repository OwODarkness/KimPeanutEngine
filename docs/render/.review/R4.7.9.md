# R4.7.9 — Closest-hit world-position reconstruction

Date: 2026-09-27. Status: provisional Sponza timing gain; correctness,
equal-sample quality and provenance acceptance remain open.

## Change

`asset/shader/ray_tracing_path_tracer.rchit` computes hit position as
`gl_WorldRayOriginEXT + gl_HitTEXT * gl_WorldRayDirectionEXT`, removing three
vertex-position loads and three object-to-world transforms that were used only
for position interpolation. Index, UV and normal loads remain. `HitPayload` is
unchanged because no register-allocation evidence supports a payload change.

## Compile and runtime

- Compiled baseline and candidate as Vulkan 1.2 closest-hit shaders with
  `glslangValidator`, optimized both with `spirv-opt --O`, then ran
  `spirv-val`; both passed. The optimized SPIR-V changed from 11,344 to 10,460
  bytes and from 602 to 560 instructions (-42, or 7.0%). This is compiler IR
  evidence, not hardware ISA or register/spill evidence.
- RelWithDebInfo Vulkan Sponza runs loaded the candidate pipeline and reported
  `path_trace_active=true`, 4 samples/dispatch, 8 continuation bounces, a
  1094x619 viewport, camera `(10.8074, 1.5922, 0)`, complete tracked texture
  residency (469,885,796 bytes), and 9,539,005 triangles.
- Runtime `capture.screenshot` plus polling produced candidate and baseline
  Sponza PNGs. Near-matched accumulation ended at 1324 baseline and 1336
  candidate samples. Their RGB MAE is 0.10/255, channel-difference p95 is 1,
  maximum is 21; visual inspection shows no geometry, shading or shadow change.
- A candidate Cornell launch loaded `level/cornell_box.level`, but path tracing
  stayed inactive (`geometry_records=0`, invalid TLAS) and Vulkan command-buffer
  submission then failed. No Cornell candidate image was captured; see
  `save/logs/2026-09-27/KimPeanutEngineLog-2026.09.27-18.03.24.txt`.

## Matched Sponza performance

Each process started from the same RelWithDebInfo executable and fixture. Runs
used Vulkan, 1094x619, the same camera, capture graph, 4 SPP, 8 bounces and
complete 469,885,796-byte texture residency. Every window collected 120 warm-up
frames and 300 samples; path tracing remained active. GPU: NVIDIA GeForce RTX
4070 Laptop GPU, driver 595.71. Three independent windows per shader:

| Shader | PT GPU p50 per window (ms) | PT p95 mean (ms) | Total GPU p50 mean (ms) | Total GPU p95 mean (ms) |
| --- | --- | ---: | ---: | ---: |
| Baseline | 24.377, 24.405, 24.360 | 25.567 | 29.023 | 30.108 |
| Candidate | 23.560, 23.412, 23.948 | 24.661 | 28.315 | 29.047 |

The mean of the three PT p50s improved 3.04%; total GPU p50 improved 2.44%.
Every candidate window's PT and total GPU p95 was below the corresponding
baseline window. An additional baseline/candidate pair with 22 telemetry
samples each reported graphics clocks 780–1020 vs 795–1020 MHz, memory at
6001 MHz, temperatures 57–60 C, and P4/P5 counts 20/2 vs 21/1. Its PT p50 was
24.368 vs 22.821 ms and total GPU p50 was 29.060 vs 27.646 ms. These results
support a repeatable Sponza improvement; they do not establish hardware
register or traversal attribution.

## Independent source and evidence review — 2026-09-27

Scope: working tree against `54283a6`; reviewed only the closest-hit edit,
its consumers and saved artifacts. The section-packet cache, Sponza light
intensity edit, profiler UI, GUI launch and BLAS flag edits are separate work
and were preserved. Plan: [R4.7 GPU strategy](../.plan/R4.7-gpu.md#r479--reduce-hit-cost-and-live-state-first).

### Source assessment

`asset/shader/ray_tracing_path_tracer.rchit:145` uses world-space origin and
direction with the intersection parameter from the same ray. This agrees with
the [Khronos GLSL ray-tracing definitions](https://github.com/KhronosGroup/GLSL/blob/main/extensions/ext/GLSL_EXT_ray_tracing.txt):
the ray parameter is invariant across coordinate spaces and `gl_HitTEXT` aliases
the current closest-hit parameter. Nonuniform transforms do not require an
extra conversion of that parameter. Index/UV/normal interpolation and inverse-
transpose normal handling remain intact. No demonstrated semantic defect was
found in the position substitution; floating-point equivalence is not assumed.
No ownership, shader interface or payload-layout change was introduced.

### F1 — P2, open: correctness acceptance is incomplete

Locations: closest-hit shader `:145` and
`asset/shader/ray_tracing_path_tracer.rgen:188,293`.
The new arithmetic supplies positions used with fixed 0.002 world-space
secondary/visibility offsets. Large origins, long rays, grazing intersections
and thin geometry can expose reconstruction/offset errors that a normal Sponza
camera does not exercise. This is a validation gap, not a reproduced artifact.
Run the planned precision/transform fixtures and Cornell with Debug Vulkan
validation enabled before accepting general-scene correctness. No new Debug
correctness run is evidenced by the current stage record.

The Cornell log at 18:03:24 confirms timestamp-query failure followed by failed
queue submission. Startup zero records and post-cleanup zero resource counts
do not identify an offending closest-hit invocation. Do not attribute that
failure to the shader change without first-fault evidence.

### F2 — P2, open: exact quality/provenance gates remain unclosed

The saved comparison uses 1324 versus 1336 samples, so its reported image error
is not an exact equal-sample acceptance result. This review visually inspected
the baseline and near-matched candidate PNGs and found no obvious regression,
but did not independently recompute the prior MAE. Repeat at identical sample
count, and retain source/binary/shader and fixture hashes plus actual validation
state. The six raw window files do not contain a complete build/layer/fixture
identity manifest. Preserve the current user light intensity separately rather
than comparing new runs to old fixture settings implicitly.

### Timing cross-check and verdict

Parsed all six `r479-{baseline,candidate}-sponza-window-{1,2,3}.json` artifacts.
Each confirms 120 warm-up frames, 300 samples, active PT, matching camera,
four SPP/eight bounces and 469,885,796 resident texture bytes.
The mean of PT p50s is 24.381019 → 23.639984 ms (-3.04%); mean total GPU p50
is 29.023349 → 28.314832 ms (-2.44%), confirming the recorded arithmetic.
For comparison, the medians of PT p50s are 24.377456 → 23.560192 ms;
do not confuse mean-of-percentiles with one pooled percentile. The data supports
a modest Sponza gain under recorded conditions, not complete stage acceptance
or reduced hardware register pressure. Payload/live-state work remains deferred.

Validation in this review: source/API inspection, JSON re-analysis, log inspection
and image viewing only. No build, tests, runtime launch or code changes.
Both findings remain open; R4.7.9 remains provisional.
