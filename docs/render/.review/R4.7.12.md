# R4.7.12 — Ray-cone texture footprint

Date: 2026-09-27. Status: prototype implemented and evaluated; not accepted as
a performance optimization.

Plan: [R4.7 GPU strategy](../.plan/R4.7-gpu.md).

## Scope and candidate

Adds `ray_cone_filtering`, an opt-in path-trace probe mode. Raygen estimates
pixel angular spread from adjacent inverse-view-projection rays; closest-hit
propagates updated cone width through each continuation hit and derives mip
LOD from triangle UV/world area and each base-color texture's dimensions.
Default Beauty sampling remains
unchanged. The existing metallic/roughness inputs stay at LOD 0 in both modes;
the prototype does not yet provide a shared channel LOD policy.

Source locations: `../../../asset/shader/ray_tracing_path_tracer.rgen:300`,
`../../../asset/shader/ray_tracing_path_tracer.rchit:144`,
`../../../engine/runtime/render/path_trace_probe_mode.h:17`, and
`../../../engine/runtime/runtime_global_context.cpp:153`.

The direct-light Sponza fixture has one authored directional light, so
importance-sampled multi-light selection was not justified or attempted.

measured frames per window, complete 469,885,796-byte texture residency,

The corrected shader also ran in a freshly rebuilt Debug Vulkan executable

## Findings

### F1 — P2, open: footprint accuracy and all-channel filtering

The cone spread update uses a bounded roughness heuristic and the footprint
uses triangle area estimates. Thin UV triangles, mirrored/nonuniform transforms,
texture atlas seams, high-frequency detail under camera motion, metallic and
roughness mips, and equal-wall-time error were not validated. The candidate
must stay opt-in and must not be described as unchanged quality.

### F2 — P2, resolved: retain default LOD behavior

The experiment is slower across all three matched windows. The default path
continues to use its prior base-color sampling and explicit LOD-0
metallic/roughness sampling; no quality-changing cone behavior is enabled
without selecting the probe mode.

## Review verdict

The bounded experiment is complete as a measurement and is rejected as a
performance optimization on this fixture. Keep it opt-in for future texture
quality studies; do not change the default sampler or claim a speedup.
