# R7.5 review — Combined raster acceptance

The allocation and combined runtime gates passed on 2026-11-06. Core sign-off remains open for [R7.1 focused SSAO acceptance](../.plan/R7.md#r71--spatial-ssao-and-ambient-diffuse-integration).

| Gate | Evidence |
| --- | --- |
| HDR ownership | Lighting and fog write successive versions of one pooled SceneHdr. Fog explicitly loads it. Tests check the same physical target, the next HDR consumer and rejection of an unproduced load. |
| Output parity | Vulkan and OpenGL Sponza base-color, fog-off and transmittance captures match R7.4 pixel-for-pixel. Fog-on differs by at most one 8-bit level per channel. Disabled and zero-density captures are identical. |
| Raster modes | All-off, SSAO-only, TAA-only, fog-only and combined captures pass on Vulkan and OpenGL shadow maps and Vulkan hybrid ray queries. The indoor analytic fog cases and a new procedural terrain generation pass on both APIs. |
| Path tracing | Vulkan switches from both raster shadow modes into fixed raw path tracing and returns to the original mode. Raster toggles leave all three effects inactive during PT and accumulation continues. TAA history recovers after the return. |
| GPU budgets | 3.366–3.407 ms total p95 with shadow maps and 3.418–3.447 ms with hybrid ray queries, both below 8.5 ms. Fog is 0.022528 ms and 0.021504 ms p95, respectively, below 0.5 ms. |
| Texture budget | 32,440,320 bytes (30.94 MiB) active incremental Vulkan storage in all six windows at 1094×631, below the 32 MiB cap. The deleted target accounted for 5,611,520 allocated bytes. |
| SSAO checkpoint | The compact fixture returns pixel-for-pixel to its feature-off baseline after disabling AO on both APIs. Raw and filtered captures are available. The controlled material-AO overlap comparison and frozen planar/silhouette tolerances remain open. |

[Execution evidence](../../../.spec/journal/2026-11-06-render-r7-5-combined-acceptance.md) records commands, fixture settings and remaining validation. Reflections, SSR and volumetric fog remain separate design decisions in the [stage plan](../.plan/R7.md#r75--core-acceptance-and-follow-up-decisions).
