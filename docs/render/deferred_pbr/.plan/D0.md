# D0 — Deferred PBR prerequisites

Parent: [Deferred PBR plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

## Design

Keep backend scheduling/resource ownership separate from short-lived
`CommandRecorder` implementations. Keep readback behind a borrowed common
interface owned by Graphics services. Preserve the unlit ScenePass and the
Vulkan/OpenGL smoke baseline while the new pass policy is introduced.

## Acceptance

- Render can add pass policy without restoring deprecated OpenGL global state
  or backend-owned scene content.
- Render has no native attachment or synchronization access.
- Both backends retain the existing frame-local lifetime and smoke baseline.

Status: complete. Detailed evidence is in the
[deferred-PBR journal](../../../../.spec/journal/render-deferred-pbr.md).
