# D5 — Deferred lighting and presentation

Parent: [Deferred PBR plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

## Design

`DeferredLightingPass` is the sole `SceneHdr` producer. It reconstructs world
position from the sampled G-buffer, evaluates metallic-roughness
Cook-Torrance lighting from the versioned light binding, consumes the
directional shadow map with frame-local transforms and PCF, and writes HDR.
`ToneMapPass` produces the stable LDR `SceneColor` before editor composition.

The runtime capture path names semantic views. Render converts depth, normals,
material parameters, and shadow visibility into an owned RGBA8 target before
Graphics readback. The visible HDR panorama remains separate from derived IBL
artifacts. Resource produces irradiance, roughness-filtered radiance, and a
BRDF LUT; Render owns their bindings. The prefilter is a 2D roughness atlas
until common Vulkan upload supports cube faces and mip levels.

## Acceptance

- Vulkan/OpenGL runtime captures are deterministic, comparable, and visually
  inspectable for final color and diagnostic views.
- Environment radiance, material IBL, capture conversion, and tone mapping
  preserve Asset → Resource → Render → Graphics ownership.
- D5.1–D5.7 landing evidence remains in the [journal](../../../../.spec/journal/render-deferred-pbr.md).
