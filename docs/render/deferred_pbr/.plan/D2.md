# D2 — Attachment-capable common graphics contract

Parent: [Deferred PBR plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

## Design

The common target description supports multiple named color attachments,
optional or depth-only depth, sampled attachments, load/store operations, and
pipeline-format compatibility. `RendererFrameTargets` is Render-private and
rebuilds a named extent/format set; Graphics owns physical allocation,
transitions, framebuffers, and safe retirement.

Vulkan and OpenGL translate the same descriptions without exposing native
types. The initial contract is single-sample only. Sampled-MSAA resolve is a
future contract, not an implicit extension.

## Acceptance

- Multi-attachment, depth-only, sampled, resize, capture, and teardown coverage
  passes on Vulkan and OpenGL.
- A no-depth pipeline does not discard fragments, and both backends retain
  caller-provided attachment formats.
