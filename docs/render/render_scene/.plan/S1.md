# S1 — Common scene-recording boundary

Parent: [Render Scene plans](../PLANS.md) · Roadmap: [TODO](../TODO.md)

Move scene content out of backend ownership into Render-owned scene policy.
`RenderScene` records common commands using borrowed resolved resources and
frame-local bindings; Vulkan/OpenGL only encode the commands and manage native
GPU state.

Acceptance: scene recording exposes no native API types above Graphics and the
same Render scene boundary can drive both backends.

Status: complete for the current reconstruction; remaining legacy assumptions
are tracked in the parent TODO.
