# L2D4.1 — Common Streaming Geometry

- Status: proposed
- Parent: [L2D4 — Model Snapshot and Common Renderer](L2D4.md)
- Depends on: [L2D4.0](L2D4.0.md)
- May run independently of: [L2D4.2](L2D4.2.md)

## Goal

Add the smallest reusable Graphics contract for immutable and frame-updated
geometry. Prove it without Cubism before Live2D consumes it.

## Contract changes

Add common `BufferDesc`, `BufferRole`, `BufferUpdateMode`,
`IndexElementType`, `VertexBufferView`, `IndexBufferView`, and `GeometryView`
types described by the parent plan. Extend `RenderBackend` with `CreateBuffer`
and `WriteFrameBuffer`, and `CommandRecorder` with `BindGeometry`.

Rules:

- zero capacity, null non-zero initial data, initial-size overflow, and invalid
  enum values fail creation;
- immutable initial data is copied before creation returns and immutable writes
  fail;
- per-frame buffers are created without initial data and must be written before
  their first bind in each frame that uses them;
- per-frame writes require an active frame and target only its current slot;
- write offset/size arithmetic is overflow checked;
- a geometry view rejects duplicate/missing pipeline bindings, invalid handles,
  unaligned index offsets, and a non-Index index buffer;
- `DrawIndexed(first_index, vertex_offset)` is element based and identical on
  both backends;
- old raw creation calls and `BindMesh` remain behaviorally compatible.

## Backend work

### Common

- Centralize description and geometry-view validation.
- Make invalid binding suppress the draw and provide a test-observable failure;
  never continue with the previously bound mesh.
- Add fake-backend contract tests before native implementation.

### OpenGL

- Store the declared role/update mode/capacity with each buffer handle.
- Allocate per-frame buffers with dynamic usage and update only the current
  frame storage.
- Bind every declared vertex stream to the pipeline VAO by binding number.
- Bind UInt16 or UInt32 index format from `IndexBufferView`.
- Implement non-zero base vertex with the appropriate base-vertex indexed draw;
  the current ignored `vertex_offset` behavior is not acceptable.
- Reset recorder caches when explicit geometry changes, a handle dies, or a
  frame starts; no stale `BindMesh`/`BindGeometry` suppression.

### Vulkan

- Back `PerFrame` handles with one host-visible allocation per frame slot, or an
  equivalent staged implementation whose ownership is internal to Graphics.
- Select a slot only after `BeginFrame` has waited its fence; flush non-coherent
  memory when required.
- Bind multiple vertex buffers/offsets and the selected index type through the
  common view.
- Destroy all slot allocations only at an existing safe lifetime point.

## Tests

Add contract cases for:

- two vertex bindings plus UInt16 indices;
- non-zero buffer offsets, `first_index`, and `vertex_offset`;
- immutable-write, outside-frame-write, overflow, wrong-role, and stale-handle
  rejection;
- frame slots A/B/A containing different vertex positions without cross-frame
  corruption;
- `BindMesh` followed by `BindGeometry` and the reverse, proving cache reset;
- creation failure and shutdown returning buffer-manager live counts to zero.

Extend `GraphicsSmoke` with a tiny animated two-stream indexed quad rendered
for more than `2 * GetFramesInFlight()` frames on OpenGL and Vulkan. Read back a
stable frame or sample known pixels so compilation cannot satisfy the gate.

## Gate

`GraphicsContractTest` and both `GraphicsSmoke` backends pass, including base
vertex and frame-slot reuse. No Live2D include/name exists under Graphics. Only
then may L2D4.3 depend on this contract.
