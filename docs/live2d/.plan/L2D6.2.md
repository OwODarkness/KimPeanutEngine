# L2D6.2 — Instance-Local Clip Library

- Status: proposed
- Parent: [L2D6 — Authored Motion and Expression Playback](L2D6.md)
- Depends on: [L2D6.1](L2D6.1.md)

## Goal

Turn immutable Product V2 animation bytes into a complete instance-owned SDK
clip library without exposing SDK types or sharing mutable motion objects.

## Construction transaction

During `Live2DModelInstance::Create`:

1. receive a non-zero, non-reused instance serial from `Live2DSystem` and
   retain the immutable `Live2DModelResource` as today;
2. validate typed motion/expression keys and configured bounds again;
3. parse each motion with pinned R5 consistency checking;
4. apply model3 fade overrides only when present;
5. apply authored EyeBlink/LipSync effect IDs to each motion;
6. parse every expression and bind its unique name;
7. create instance-local motion/expression managers and internal event adapter;
8. initialize the model's saved-parameter checkpoint and fixed pending-write,
   transition, token, and event capacities;
9. publish the instance only after model, static render data, every clip, and
   every manager are valid.

Use temporary RAII owners for every SDK allocation. On failure, destroy queues
and managers first, then parsed expressions/motions, then the model/MOC and
lifecycle lease. Do not place raw SDK pointers in `Live2DModelResource` or a
public header.

Preload all clips for L2D6. This bounds failure to instance construction and
keeps `PlayMotion`/`SetExpression` deterministic and allocation-light. Record
clip count and byte totals for later profiling; do not add async or lazy loading
without evidence.

## Lookup contract

- Motion lookup uses exact case-sensitive UTF-8 `(group, index)` identity.
- Expression lookup uses exact case-sensitive UTF-8 name identity.
- Enumeration APIs, if required by the viewer/test harness, return SDK-free
  borrowed metadata views whose lifetime is the retained resource, not SDK
  objects.
- Missing keys return stable diagnostics and leave managers unchanged.
- Product V1 has a valid empty library; requests report that the asset must be
  reimported for authored playback.

## Isolation tests

- Create two instances from one V2 resource and prove shared resource identity
  but distinct SDK motion/expression addresses through test-only counters.
- Start different clips, priorities, and expressions and interleave updates;
  parameter values and manager state remain independent.
- Destroy the Asset wrapper before both instances; clip playback remains valid.
- Destroy one instance during the other's transition; the survivor remains
  valid and emits no foreign event.
- Inject failure at every clip/manager allocation and parse step; lifecycle
  live counts return to baseline and no partial instance escapes.
- Exhaust the test-controlled instance serial source and reject creation
  without wrapping or reusing an identity.
- Repeated create/destroy and SDK-off builds remain clean.

## Gate

All typed clips parse transactionally, public/runtime headers remain SDK-free,
two-instance isolation is proven, and failure/shutdown counters return to zero.
No playback semantics beyond lookup/construction land before L2D6.3.
