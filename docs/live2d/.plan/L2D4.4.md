# L2D4.4 — Packed Clipping Masks

- Status: proposed
- Parent: [L2D4 — Model Snapshot and Common Renderer](L2D4.md)
- Depends on: [L2D4.3](L2D4.3.md)

## Goal

Add deterministic ordinary and inverted Cubism clipping through one
module-owned packed RGBA atlas without introducing native API state.

## CPU mask planner

Implement an SDK-free `Live2DMaskAtlasPlanner` that:

1. interns identical ordered mask-source sets as one context;
2. finds contexts used by at least one visible clipped drawable;
3. computes the union of their clipped drawable bounds from current positions;
4. expands non-empty bounds by the frozen 5% margin;
5. assigns active contexts deterministically by context index to atlas,
   channel, and region according to the L2D4.0 capacity table;
6. calculates model-to-mask and model-to-atlas-sample matrices;
7. rejects zero-area/non-finite bounds and capacity overflow with context data.

The planner returns plain values and has no Graphics or Cubism dependency.

## GPU resources and passes

When static data contains clipping, the proxy owns one sampled
`RGBA8_UNORM` target at the frozen resolution and the mask pipeline variants.
Creation fails if the backend cannot render to and sample that format.

Frame submission becomes:

```text
validate snapshot and upload positions
  -> plan active masks
  -> begin mask target, clear to (1,1,1,1)
  -> draw source drawable ranges into assigned channels/regions
  -> end mask target (sample-readable)
  -> begin color target
  -> draw ordered model ranges, sampling mask when present
  -> end color target
```

Mask-source draw submission honors its current positions, texture alpha,
opacity rules, culling, and mask matrix according to L2D4.0. Scissor each atlas
region to prevent filtered writes crossing a neighbor. Main masked pipelines
bind both the model texture and atlas texture, select the assigned channel, and
apply ordinary or inverted polarity. Unclipped drawables use the already-proven
L2D4.3 path.

Do not begin one render target while another is active. A failed mask plan or
resource binding suppresses the complete model frame; do not render unclipped
parts as an approximation.

## Tests

Pure planner tests cover:

- one context; identical-set sharing; multiple channels and subdivisions;
- deterministic assignment independent of consumer drawable order;
- bounds/margin/matrix numeric goldens;
- invisible consumers, empty source geometry, zero-area bounds;
- exact capacity and capacity-plus-one;
- ordinary and inverted polarity.

Backend readback cases cover:

- one source masking one drawable;
- two drawables sharing a context;
- contexts in different channels/regions;
- soft transparent texture edges without atlas bleed;
- inverted clipping;
- a moving mask source over repeated frame slots.

Compare center pixels exactly within the L2D4.0 channel tolerance and compare
filtered boundaries using its edge tolerance. Inspect at least one atlas
readback during development so an all-white/all-zero false positive cannot
pass only from final color.

## Gate

All planner tests and OpenGL/Vulkan clipped readbacks pass. The result contains
no direct framebuffer/image barriers above Graphics. Unsupported high-precision
and offscreen cases fail before proxy publication rather than selecting an
approximate mask path.
