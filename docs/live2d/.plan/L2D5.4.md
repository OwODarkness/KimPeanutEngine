- Status: proposed
- Parent: [L2D5 — V1 Evidence Completion and Viewer Closeout](L2D5.md)

## Goal

Make the V1 ledger true and the L2D6 entry gate checkable, then update the
artifacts that currently describe a viewer that was not built.

## Ledger

- Re-audit every V1 acceptance item in [TODO.md](../TODO.md) and replace each
  remaining open marker with either a pass and its evidence pointer, or an
  explicit accepted limitation naming the reason and the residual risk.
- Update the V1 acceptance criteria in
  [live2d-v1-rendering.md](../../../.spec/specs/live2d-v1-rendering.md) to match,
  including the item 8 defect entry and the resize criterion.
- Record the reopened `model/rock1-bl/rock2` content gap as deferred with its
  reason, if L2D5.0 decides it is out of scope.

## Documentation corrections

- L2D5's deliverable is written as a separate `KimPeanutLive2DViewer` binary.
  The landed design makes the viewer an `IApplicationHost` registered from
  `engine/module/module_bootstrap.cpp` and run through `KimPeanutEngine.exe`.
  Correct the roadmap and any plan or README text that still names a separate
  binary.
- Record the capture-view rename and its tooling alias in the Live2D README's
  capture workflow.
- Record the resize launch option and the shutdown assertion in the same place.

## L2D6 handoff

- Confirm the [L2D6](L2D6.md) entry gate sentence — one loaded model proved
  through update, snapshot, submission, presentation, capture, resize, and clean
  shutdown — is now true, and point it at this stage's journal.
- Remove the "L2D5 evidence remains incomplete" annotation from
  [L2D6.0](L2D6.0.md) once it is no longer accurate.
- Confirm nothing in L2D5 changed the product bytes, the instance lifetime
  contract, or the L2D4 submission boundary that L2D6.1–L2D6.3 build on. If
  anything did, L2D6.0's frozen decisions must be revisited before L2D6.1.

## Gate

Aggregate V1 acceptance is green with per-item evidence pointers, no V1 item is
silently open, the documentation names the viewer that exists, and L2D6's entry
gate is checked rather than assumed.
